Built Crossy Road using Claude.
It has the basic mechanics and core functionalities of Crossy Road, with minor differences in the color palette, which follow a sunset theme, and the perspective, which is more top-down than the original. 

Controls: WASD or the arrow keys to move, and a point is scored for each lane crossed. The game is over when the chicken collides with a moving car or falls into the water. I used Claude (Sonnet 5) to build the game.
Overall strategy for prompting: I tried to start with the visuals, and then refined the mechanics from there. Much of it was getting the perspective correct, and I ended up opting for a more direct top-down view.
